# Sample Output: review

Source of truth: artifact under review, design document, and current diff.

Scope: findings first, with file evidence and a clear verdict.

Validation: distinguish inspected files, commands run, and checks that could not run.

Gap handling: separate merge readiness from release readiness when evidence is incomplete.

Review integration table:

Role | Verdict | Key evidence | Decision impact | Residual risk

Fact / inference boundary: label inspected facts separately from reviewer inference, judgment, or recommendation.
