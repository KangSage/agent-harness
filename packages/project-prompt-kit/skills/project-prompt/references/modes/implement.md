# implement

Korean: `구현`

Purpose: build or modify code, content, or project artifacts.

Primary output: implementation prompt.

Required prompt fields:
- target files or surfaces
- desired behavior
- existing behavior, if known
- constraints
- implementation steps
- test plan
- rollback or blast-radius risk
- final response requirements

Guardrail: require inspection before edits, require verification before completion claims, and do not broaden scope.
