# plan

Korean: `계획`

Purpose: turn scoped intent and source material into a reviewed implementation plan before work begins.

Primary output: planning brief.

Required prompt fields:
- goal
- non-goals
- scope
- assumptions
- options
- decisions
- affected domains
- validation strategy
- implementation boundary
- rollback or fallback
- go/no-go verdict

Guardrail: do not implement, edit files, or claim readiness while planning blockers remain unresolved.
