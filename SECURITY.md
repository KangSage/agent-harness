# Security Policy

## Reporting a Vulnerability
If you discover a security issue, please open a private security advisory or contact the maintainer directly.

Please include:
- A clear description of the issue
- Reproduction steps
- Potential impact
- Suggested remediation (if available)

## Safety Defaults in This Repository
- No telemetry by default
- Local-first behavior
- Redaction before sharing prompts externally
- Prompt-injection boundary notes in package docs
