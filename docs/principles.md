# Principles

1. **Host-neutral contracts**: prompt kits should be portable across Codex, Claude, and generic renderers.
2. **Safety by default**: local-first operation, no network calls, no telemetry default, redaction guidance, and prompt boundaries.
3. **Composable packages**: each package should be independently understandable and adoptable.
4. **Minimal scaffolding first**: start with a small, verifiable foundation before adding automation.
5. **No private coupling**: public examples and docs must not depend on private paths, personal accounts, or local-only agent frameworks.
