# Contributing

Thanks for contributing to `agent-harness`.

## Principles
- Keep packages host-neutral and reusable.
- Prefer small, composable artifacts over heavy frameworks.
- Keep safety defaults enabled.

## Development
1. Make focused changes.
2. Run validation:
   ```bash
   bash packages/project-prompt-kit/scripts/validate.sh
   ```
3. Submit a pull request with clear rationale.
