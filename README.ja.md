# agent-harness

[English](./README.md) | [한국어](./README.ko.md) | [日本語](./README.ja.md)

`agent-harness` は、コーディングエージェントとプロジェクトエージェントで再利用できる部品をまとめる公開モノレポです。

最初のパッケージのタグライン: **リポジトリ文脈を反映する、コーディングエージェント向けプロンプトテンプレート。**

## 目的
- プロンプトキット、スラッシュコマンド、ワークフローテンプレート、バリデータ、サンプル、安全パターンを再利用しやすい形で管理します。
- Codex、Claude、汎用レンダラーで同じ意味として扱えるように、ホスト中立の契約を維持します。
- 安全なデフォルトを採用します: ローカル優先、ネットワーク呼び出しなし、テレメトリ無効、機密情報のレダクション、プロンプト境界の明示。
- 特定のローカルワークフロー、エージェントフレームワーク、個人の作業環境には結合しません。

## モノレポ構成
- `docs/` — 原則、アーキテクチャ、ロードマップ
- `packages/project-prompt-kit/` — 最初のパッケージ（`v0.1` スキャフォールド）
- `.github/workflows/validate.yml` — スキャフォールド検証 CI

## 最初のパッケージ: `project-prompt-kit`
このパッケージは、軽量でホスト中立なプロンプトキットの土台です。引き継ぎ専用ではなく、実装、レビュー、デバッグ、ドキュメント作成など、一般的なプロジェクト作業のプロンプト契約を扱います。

コマンド契約:
- 主コマンド: `/prompt`
- 正式エイリアス: `/project-prompt`

参照: [`packages/project-prompt-kit/README.md`](./packages/project-prompt-kit/README.md)

## クイック検証
```bash
bash scripts/validate.sh
```

生成されたプロンプトにはプロジェクト情報が含まれることがあります。共有する前に必ず確認してください。生成されたプロンプトの成果物は、このリポジトリではなく、作成したユーザーまたはプロジェクトに属します。
